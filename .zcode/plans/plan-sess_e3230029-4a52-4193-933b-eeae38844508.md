# StdLib 两个小需求:Dictionary.Remove + List.Contains

## 改动
1. **`assets/libs/StdLib/Dictionary.cs`** — `TryGetValue` 后新增(遵循文件既有风格):
   ```csharp
   public bool Remove(K key)
   {
       if (key == null) throw new Exception("Key cannot be null");
       if (LuaInterop.Get<V>(_table, key) == null) return false;
       LuaInterop.Set(_table, key, null);   // 降级为 self._table[key] = nil
       Count--;
       _keys.Remove(key);                   // 保持 PairsNext 迭代顺序表同步
       _version++;
       return true;
   }
   ```
2. **`assets/libs/StdLib/List.cs`** — `IndexOf` 后新增:
   ```csharp
   public bool Contains(T item)
   {
       return IndexOf(item) != -1;   // 降级为 return (self:IndexOf(item) ~= (-1))
   }
   ```
