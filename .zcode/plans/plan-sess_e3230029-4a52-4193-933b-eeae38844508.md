# 支持 string.Replace / string.Substring(含 Lua 三暗坑的运行时助手)

## 语义与暗坑处理(助手体内三坑全避)
新运行时助手(与既有 `StrSplit__` 同模式,用到才发射):
```lua
function SF__.StrReplace__(str, old, new)
    if str == nil or old == nil or new == nil then return str end
    -- gsub 的搜索串是模式串:魔法字符转义;替换串中 % 转义
    local pattern = string.gsub(old, "([%^%$%(%)%%%.%[%]%*%+%-%?])", "%%%0")
    local replacement = string.gsub(new, "%%", "%%%%")
    -- 括号截断:gsub 返回 (结果, 次数),只允许结果外逸
    return (string.gsub(str, pattern, replacement))
end
function SF__.StrSubstr__(str, start, length)
    if str == nil then return "" end
    if length == nil then return string.sub(str, start + 1) end       -- 0基→1基
    return string.sub(str, start + 1, start + length)                  -- 闭区间端点=start+length
end
```
- C# `Replace(".","-")` 等魔法字符按字面替换 ✓;`Substring` 0 基→1 基换算在助手内 ✓。
- 已声明的语义分歧(文档记录,不仿造异常):越界 Substring 在 C# 抛异常、Lua 静默返回空串。
- **char 重载免费兼容**:char 字面量已降为字符串(IRLowering:6068),`Replace('"','\'')` 走同一助手。

## 实现
1. **Emitter**:字段/flag `_emitStrReplaceSubstrHelpers` + 新 walker 对(镜像 StrSplit 三函数,IRRuntimeInvocation 分支同时匹配两名字,两助手同发射)+ `WriteStrReplaceHelper/WriteStrSubstrHelper` + `EnsureRootEmitted` 注册。
2. **IRLowering**(:2255 System_String 分支):`Replace` 且 2 参 → `IRRuntimeInvocation("StrReplace__", [接收者, old, new])`;`Substring` 1 参 → `StrSubstr__(接收者, start, nil)`,2 参 → `(接收者, start, length)`;其余字符串方法维持既有诊断。
